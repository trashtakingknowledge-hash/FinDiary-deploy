# Original source notes

The uploaded original project uses Next.js App Router, React/TypeScript components, Tailwind CSS, Zustand persisted stores, and Lucide icons. It contains pages for Overview, Transactions, Insights, Bills, Goals, and Recurring. The original frontend's mock data and Zustand stores were client-side only. This converted starter uses Flask-served HTML/CSS/vanilla JS and Oracle-backed API calls; it does not bundle the original Next.js source.

The design adaptation preserves the major visual language and dashboard composition, but it is not a pixel-perfect rendering of the React application. Features without matching backend endpoints are identified in README rather than represented as fully implemented.
